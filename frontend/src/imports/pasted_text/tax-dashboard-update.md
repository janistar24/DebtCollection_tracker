ปรับแก้ Web Application เดิมเฉพาะส่วนที่ระบุด้านล่าง

คง Design Style เดิม:
- Liquid Glass / Frosted Glass
- พื้นหลังหลักสีขาว
- Accent สีม่วง Pastel / Lavender
- ภาษาไทยทั้งหมด

- UI สะอาด ใช้งานง่าย
- เน้นลดงานซ้ำของเจ้าหน้าที่
- ข้อมูลสำคัญต้องอ่านเข้าใจได้ทันที
- Print / Export สามารถมีรูปแบบที่ต่างจาก UI บนเว็บได้

11. OWNER CODE GENERATION : FIRST NAME
==================================================

IMPORTANT:
ไม่นำคำนำหน้าชื่อ เช่น
นาย
นาง
นางสาว

มาคำนวณ

ใช้เฉพาะ “ชื่อจริง”

--------------------------------
PREFIX
--------------------------------

หา “พยัญชนะตัวแรก” ของชื่อ

ถ้าตัวอักษรก่อนหน้าเป็นสระ
ให้ข้ามสระไปจนกว่าจะพบพยัญชนะตัวแรก

พยัญชนะตัวแรกนี้ใช้เป็น Prefix ตัวอักษร

ตัวอย่าง:

กรกน

พยัญชนะตัวแรก = ก

Prefix:

ก-

--------------------------------
FIRST NAME NUMERIC CODE
--------------------------------

หลังจากใช้พยัญชนะตัวแรกเป็น Prefix แล้ว

ให้นำ “พยัญชนะ 3 ตัวถัดไป”
มาแปลงเป็นตัวเลข
ด้วย Consonant Mapping Table ของระบบ

ข้าม:
- สระ
- วรรณยุกต์
- เครื่องหมายอื่นที่ไม่ใช่พยัญชนะ

ใช้พยัญชนะเท่านั้น

Code ส่วนนี้ต้องมี “3 หลักเสมอ”

ถ้าชื่อมีพยัญชนะไม่ครบ 3 ตัวหลัง Prefix
ให้เติม 0 ทางด้านท้าย

ถ้ามีพยัญชนะมากกว่า 3 ตัว
ใช้เพียง 3 ตัวแรกที่ต้องนำมาคำนวณ
ตัวที่เหลือไม่ต้องนำมาคิด

--------------------------------
EXAMPLE
--------------------------------

ชื่อ:

กรกน

พยัญชนะ:

ก ร ก น

ก ตัวแรกใช้เป็น Prefix

ร = 7
ก = 1
น = 5

ได้:

ก-715

ตัวอย่างชื่อสั้น:

กรน

ก = Prefix

ร = 7
น = 5

ไม่มีพยัญชนะตัวที่ 3

ให้เติม 0

ผล:

ก-750

ในทุกส่วนที่แก้:

- Web UI = Liquid Glass Pastel
